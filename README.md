# Dr. Alexandre Magno — prévia conceitual

Adaptado diretamente do ZIP `caroline-vilas-boas-menu-cards(1).zip`, conservando CSS, navegação, animações e estrutura visual.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Produção

```sh
npm run build
npm run preview
```

Também pode servir os arquivos estáticos da raiz. A prévia usa noindex/nofollow.

## Pendências

- Foto CSI de 265×265 provisória: substituir por retrato autorizado em alta resolução; o retrato é exibido sem ampliação.
- Identidade visual e símbolo provisórios, sem logo oficial.
- Confirmar endereço exato, contatos e modalidades de atendimento com o profissional. WhatsApp institucional da CSI.
- Fontes, ícones e mapa dependem de conexão externa.
- Não há galeria de fotos da clínica nem depoimentos inventados.
